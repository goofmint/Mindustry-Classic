### デスクトップ起動の代わりにブラウザ版で確認した理由
このセッションにはディスプレイが無い。`./gradlew :desktop:run` は LWJGL の `glfwGetMonitorPos` で NullPointerException になり、`core/assets/crash-report-*.txt` を残して終わる(過去タスクで確認済み。今回は再試行していない)。そのため §7.2 の 1〜10 は **すべて HTML ビルド(GWT)で確認した**。ゲームロジック(`core`)はデスクトップと同じソースなので挙動の確認には使えるが、LWJGL 固有の部分(ウィンドウ、ファイルへのセーブ、フォント描画)は確かめていない。**デスクトップ版での通し確認は利用者が改めて行う必要がある**(末尾「利用者に残す確認」)。

### 注意
`:html:dist` を作り直した後、同じブラウザで再読み込みすると古い `html.nocache.js` がキャッシュから使われ、古い順列(`.cache.js`)が読まれた。修正後の確認は新しいブラウザプロファイルで行い、読まれた `.cache.js` が新しいものであることを確かめた。python の `http.server` は時々 `ERR_CONNECTION_RESET` を返し、アセットの読み込みに失敗して灰色や黒の画面になる。その回はやり直した。

### 操作の方法
Playwright をデーモンとして常駐させ、1 つのページを HTTP 経由でクリック、キー押下、スクリーンショットで操作した。回転は `R`/`E` を 120ms 押し続ける必要があった(瞬間的な押下はフレームの入力ポーリングに拾われない)。建設はプレイヤーから約 8 タイル(`placerange` 66)以内に限られる。
