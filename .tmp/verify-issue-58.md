## 手順

### 机上計算
1. `./gradlew :core:test --tests io.anuke.mindustry.game.BalanceModelTest -i` を実行し、標準出力の `[BalanceModel]` 行を読んだ
2. `defaultDefenseHoldsFirstWaves` が、初期配置の砲台(アラート)で wave 1〜5 の余裕が 0 以上であることを確かめる。比べるために、リンターとファザーの値も出す

### ブラウザでの実測
1. `./gradlew :html:dist` の出力 `html/build/dist` をビルドごとに別のディレクトリへ写し、127.0.0.1:8767 で配信した(`ThreadingHTTPServer` の待ち行列を広げた小さなスクリプト)
2. Playwright を常駐させ(ポート 9335)、HTTP 経由でクリック、マウス移動、スクリーンショットを送った。ブラウザは常に 1 つだけ動かした
3. メニュー: Play (668,363) → New game (668,305) → prototype (448,255)。ウェーブ、ふつう
4. 何もしない回: 開始後はマウスを左の砲台 (575,303) の上に置いたまま(電力と体力の表示を出すため。クリックはしない)、30 秒ごとに画面全体を撮った
5. 構成 C: (x, y-4) のコンベアを右クリック長押しで壊し、クラフトタブ (1055,490) → CodeRabbit (1027,600) を選んで (640,463) に置いた。そのあとは操作せず、30 秒ごとに撮った(CodeRabbit を選んだままなので、マウスの位置に置く場所の枠が出るが、クリックはしていない)
6. HUD の「WAVE n」は、次に出る wave の番号を表す(wave n-1 の敵が出た直後に n になる)。「WAVE 6」で次のウェーブの残り秒数が出たら、wave 5 の敵をすべて倒したことになる。敵が残っている間は残り秒数ではなく敵の数が出る
